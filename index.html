Terra Invicta Tech Tree

Interactive, up-to-date technology and project tree viewer for Terra Invicta — prerequisites, research costs, effects and unlocks.

An interactive, regularly updated technology tree viewer for Terra Invicta, the grand strategy game by Pavonis Interactive. Browse every technology and project in the game: prerequisites, research costs, effects, unlocked modules, habs and ship parts.

  • Full tech tree graph with search and filtering
  • Up to date with the latest stable and experimental game versions
  • Research cost and prerequisite chains for every tech and project
  • Ship drives comparison chart
  • Available in 12 languages: English, 简体中文, 繁體中文, Deutsch, Español, Français, 日本語, Polski, Português, 한국어, Русский, Українська

This is an actively maintained fork of the original Terra Invicta tech tree website. Source code on GitHub.
